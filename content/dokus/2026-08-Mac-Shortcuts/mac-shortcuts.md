Am Montag hatte ich meine ersten Berührungspunkte mit Apple Computern, wobei mir
aufgefallen ist, dass die Bedienung stärker von Windows abweicht als ich gedacht

## Vorgehen

Das folgende ist eine Liste mit den Shortcuts, welche ich voraussichtlich am
meisten brauchen werde.

# Mac Shortcuts

## cmd + F

Durchsucht ein Dokument oder eine Internetseite.

### cmd + W

Schliesst aktuelles Fenster.

### cmd + Q

Beendet das aktuelle Programm.

### cmd + T

Öffnet einen neuen Tab

### cmd + R

Lädt die Seite neu.

### cmd + N

Öffnet ein neues Finder Fenster.

### cmd + Tab

Gibt eine Ansicht aller offenen Programme, und lässt dich bei erneutem Drücken
von Tab wechseln.

### Control + ↑

Zeigt alle offenen Fenster

### Control + ← / →

Switched Zwischen Desktops

### cmd + Shift + 3

Screenshotted den gesamten Screen.

### cmd + Spacebar

Öffnet die Suche, welche nach programmen, Ordnern und Files suchen kann.
Ausserdem können im Suchbarren rechnungen eingegeben werden.
